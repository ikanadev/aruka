# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

React 19 + TypeScript frontend for the Aruka chat application. Communicates with the Go backend via Connect-RPC using generated protobuf types. There are no tests in this project.

## Commands

```bash
npm run dev           # start Vite dev server
npm run build         # tsc type check + Vite build
npm run lint          # oxlint static analysis
npm run lint:fix      # auto-fix lint issues
npm run format        # oxfmt formatter
npm run format:check  # check formatting without applying
```

## Environment

`VITE_API_URL` — backend base URL (defaults to `http://localhost:5000`)

## Architecture

**Stack:** React 19, TanStack Router (file-based, auto code splitting), TanStack Query, Mantine v8, Zustand, Connect-RPC

**Path aliases** (configured in `vite.config.ts`):

| Alias | Path |
|---|---|
| `@assets` | `src/assets` |
| `@common` | `src/common` |
| `@connect` | `src/connect` (generated proto types — do not edit) |
| `@features` | `src/features` |

**RPC clients** (`src/common/utils/clients.ts`): `chatClient` and `providerClient` — singleton Connect-RPC clients used everywhere; import from here rather than creating new clients.

**Routing:** Routes live under `src/routes/`. The file `src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin on dev/build — never edit it manually.

**React Query config** (`main.tsx`): `staleTime: Infinity`, `refetchOnMount: false`, `refetchOnWindowFocus: false` — queries are treated as effectively static until explicitly invalidated.

**Data → state pattern:** React Query fetches data from the backend; `useEffect` syncs the result into Zustand stores. Components read from Zustand, not directly from query results. Example: `use-chat-messages.ts` fetches via React Query then calls `store.setMessages(...)`.

**Feature structure** (`src/features/chats/`):

```
components/   # presentational React components
data/         # React Query hooks (use-*.ts) and query keys
screen/       # full-page compositions
store/        # Zustand stores
utils/        # feature-scoped utilities
```

**Common utilities** (`src/common/`):

```
data/         # cross-feature React Query hooks (use-providers.ts)
hooks/        # shared hooks (useIsDark.ts)
utils/        # clients.ts, generate_id.ts, theme.ts
```

**Theme:** Mantine with `primaryColor: "violet"` and Recursive font — extend via `src/common/utils/theme.ts`.
